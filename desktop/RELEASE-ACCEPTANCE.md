# Windows 2.1.1 候选版验收

此文保留 2.1.1 对应产物的历史验收。当前 3.0.0 桌面优化及后台验证见 [VERIFICATION.md](VERIFICATION.md)。

日期：2026-10-26。平台：Windows 11 x64。
当前分支：codex/portrait-live-playback。GitHub 推送、发布和分支合并由维护者决定，本轮只准备本地候选版。

## 界面与图标

- 首页仅显示平台导航和直播间卡片，移除顶部房间输入、搜索及“正在直播”标题区。
- 侧边栏新增独立搜索页；搜索结果与首页状态分别保存，返回时保留查询与滚动位置。
- 房间号/链接入口位于搜索页，Ctrl+L 可直接打开；错误输入保留弹窗及错误提示。
- 紧凑侧边栏将次要操作收进更多工具，保留全部导航入口。
- 窗口、托盘、侧边栏、安装/快捷方式及两个 EXE 共用 Android 原始图标。
  桌面资源与 Android PNG 的 SHA-256 完全相同，ICO 包含七个 16–256 像素尺寸。

## 已确认并修复的发布问题

| 触发条件 | 原表现 | 修复与验证 |
| --- | --- | --- |
| 最新 GitHub Release 仅提供 Android APK | Windows 更新被遮挡 | 独立选择稳定 Windows 版本，五项更新行为测试先失败后通过 |
| 选择较长的 Unicode 安装目录 | 许可路径超过 Windows Installer 文件操作限制，安装失败 1304 | 紧凑许可文件名与索引；相对路径最长 87 字符，预算检查通过 |
| 只修改应用资源后重新打包 | 打包任务误用旧资源 | 显式声明资源输入，交付时对照代码、原生源码锁及验收文件 SHA-256 |
| 覆盖安装旧版本 | JDK 原生升级辅助函数清除正确检测结果，旧产品残留 | 移除该辅助调用，使用标准 MSI 三段版本检测和降级保护 |
| 安装 EXE 转发带空格的属性值 | Windows Installer 打开帮助窗口，安装未开始 | 按官方 NAME="value" 规则序列化，参数契约检查及实际安装回归 |
| Ctrl+L 创建弹窗时焦点转移 | 房间输入未获得焦点 | 在弹窗布局完成后聚焦，键盘及错误恢复流程测试通过 |

安装验收通过：MSI 当前用户安装、覆盖升级、拒绝降级、卸载、安装 EXE 安装/卸载均完成，
三次安装后的原生自检均通过，资料文件保持不变。收据中的 passed 为 true，交付脚本绑定本批文件的 SHA-256。
升级基线为相同载荷的低版本 MSI 副本，证明安装器替换行为；Android/Windows 资料格式迁移由另外的兼容性测试覆盖。

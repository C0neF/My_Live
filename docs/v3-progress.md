# V3 开发与验收记录

更新日期：2026-10-23。V3 的功能开发、有限范围对抗性审查及计划内设备回归已完成，已合入 main，应用版本更新为 2.1.0 / versionCode 29。更新内容见 [更新日志](../CHANGELOG.md)。原始逐轮调查、设备标识、配置备份、日志和安装包保留在本地忽略目录。

## 主要改动

- 直播播放：斗鱼登录态与续期、高帧率和高分辨率解码配置、首帧计时、有限恢复预算及诊断；修复 AAC 无声音填充包误输出和相同 URL 下的线路状态缓存。
- 生命周期：保持手动暂停意图，隔离旧房间回调和前台服务归属，覆盖通知、后台播放、PiP 及熄屏恢复。
- 界面：自动/手机/平板布局入口统一放入外观设置；平板直播和实时聊天各用圆角细边框容器，右侧仅保留聊天；完善搜索返回和窄窗面板。
- 平台：B 站请求门控和二维码并发取消、斗鱼弹幕故障转移、抖音旧房间身份和状态语义、虎牙房间身份处理。
- 数据：关注和标签事务、屏蔽词合并、配置导出/恢复边界、LAN 完整关注同步、WebDAV 路径及权限处理、更新下载生命周期。
- 工程：独立 QA 和设备隔离包、共享协议测试、Room schema 5、Macrobenchmark、CI 和签名发布流程。

## 已验证结果

功能验收使用版本基线 2.0.8 / versionCode 28 的最终 QA；2.1.0 的版本变更另由发布构建检查。

| 检查 | 结果与范围 |
| --- | --- |
| 本地单元及 Compose 测试 | 244 套件、1123 项，0 失败/错误/跳过 |
| 真实设备测试 | Android 12 / API 31，96 项，0 失败/跳过 |
| 手工现场流程 | 33 组通过、1 次前置状态未就绪尝试排除；覆盖实际直播、设置、配置文件、账号续期和生命周期 |
| Lint | 0 错误、51 条保留提示；原 82 条中处理 31 条，无新增压制或 baseline |
| Android 16 方向补充 | 已有 API 36 / sw800dp 平板模拟器，五格方向矩阵通过；不作为性能验收 |

R35 线路状态问题使用同一冻结测试在本地和真机先取得 3/4 业务失败，再在修复后取得 4/4 通过；正常不同 URL 切换是对照。修复将线路列表和索引发布为可观察的 PlayerState，不再以当前 URL 缓存非 Compose 字段。

最终 QA 的斗鱼 2K120 档连续播放 942.167 秒，包含全屏、PiP 和熄屏往返；2K60 连续播放 349.629 秒。两段结束诊断的丢帧、播放阶段再缓冲、停滞恢复及音频异常计数均为 0。另保留 R35 前 QA 的 959.368 秒 2K60 会话，未将不同安装包的会话混写。

解码提交和显示呈现分开计量：2K120 档跟踪处理约 120 次解码输出/秒，其中约 60.1 次提交渲染；当时显示模式为 60 Hz。独立的 2K60 主窗口呈现采样覆盖 33.250 秒、约 59.459 次/秒，最大间隔 33.833 ms，包含界面和 TextureView 合成，不能归因为独立视频帧。临时关闭弹幕证实早期约 38 fps 的 SurfaceView 样本属于弹幕层；开关已恢复。

历史音频异常房间实播 229.922 秒，44100 Hz 单声道 AAC-LC；欠载、输出错误、时间戳跳变均为 0，用户确认当前无滋滋声。不据此保证间歇问题永不再现。严格十二秒断网用例在网络恢复后无需手动点击即可继续；现有自动恢复三次耗尽后仍需手动刷新。

## 可复现检查

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleQa :app:lintDebug
.\gradlew.bat :app:compileDebugAndroidTestKotlin :macrobenchmark:assembleBenchmark
```

隔离设备回归可使用 `-PisolatedDeviceTests=true`；该模式仅改变 debug 包为 `com.mylive.app.audit`，不覆盖正式版或 QA。设备测试必须选择明确的 adb 目标。性能口径和采样命令见 [性能验收要求](performance-baseline.md)及[性能采样说明](performance-sampling.md)。

## 验收边界

- 4K 按用户要求暂缓；高分辨率配置支持不等于已通过 4K 实播验收。
- 未覆盖同账号两台真实设备同时播放及相互续期。
- 未声明 Android 16 真机性能、持续带宽拥塞或相同输入旧/新版本提升百分比。
- 自然 PiP/熄屏和后台策略已在 API 31 真机检查；模拟器方向矩阵不替代该证据。
- 正式版签名和发布产物的版本、证书与 Actions 结果在发布时另行核对。
